# Who am I?

I am Brooklyn, a current software engineer student born in 2005. I am highly interested in art an cience since I was a child; I was originally going to be a medic, but life took me to a completely different path. My first approach to programming was in 2021, when I studied a technical bachelor in informatics, making a few simple scripts in C and C++. Nowdays I mostly program in JAVA, Kotlin, Python and design Websites in HTML, CSS and JavaScript.

I currently make software on my own designed to help me and other people with different struggles... Or just to have fun!
